# Midas
Project repo for the JPMC Advanced Software Engineering Forage program

Adina Shahapure:
Completed the J.P. Morgan Software Engineering Job Simulation on Forage, where I worked on a Java Spring Boot project. The tasks covered project setup with Maven, integrating Apache Kafka, working with an H2 database, and building and exposing REST APIs. I understood how the whole codebase fits together and got hands-on with backend development tools used in real-world enterprise systems. It was a great way to learn by doing and get comfortable with Java-based backend workflows.
